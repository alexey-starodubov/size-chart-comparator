# Карточка продукта

| Поле | Значение |
|---|---|
| Номер | 220 |
| Название | Сравнение размерных сеток |
| Репозиторий | `size-chart-comparator` |
| Профиль | браузерное приложение: React + TypeScript + Vite, IndexedDB, без сервера |
| Версия | 1.0.0 (пятая партия, 2026-11-22) |

## Аудитория и задача

Продавец одежды на маркетплейсе берёт одну модель у нескольких поставщиков. Размер M у одного — 48 см в груди, у другого — 52, у третьего таблица в дюймах, а «ширина груди» у одного — полуобхват, у другого — полный обхват. Покупатели получают «маломерит» и «большемерит», возвраты растут. Нужно быстро увидеть, где одинаковая маркировка скрывает разные изделия, и подготовить честную таблицу замеров для карточки товара.

## Сценарий

1. Добавить поставщиков и их замеры: по строке или вставкой таблицы из Excel. Значения — как в таблице поставщика: 48, 48,5, 19 1/2, с единицей см или дюймы.
2. Сопоставить названия замеров поставщиков с общими типами и способом измерения. Неоднозначные строки (не сопоставлен тип, неверное значение, две строки на одну ячейку) собраны на одном экране с кнопками исправления.
3. «Сравнение»: порог, округление до мм и единица показа. Строки с разбросом строго больше порога подсвечены, пропуски — «нет данных».
4. «Для карточки товара»: таблица выбранного поставщика с подписями единиц и способа, CSV и печать.

## Функции версии 1.0

- Поставщики, строки замеров, загрузка таблицы с отчётом о пропусках и ошибках.
- Сопоставление «поставщик + название» → тип и способ; общие типы.
- Точный перевод см и дюймов (в том числе 19 1/2, 19½, 19") в целые мм, три режима округления.
- Сравнение по модели, разброс, порог, фильтр «Только больше порога», CSV.
- Таблица для карточки товара: CSV и печать.
- IndexedDB, файл проекта JSON, копия на закрытие вкладки.

## Практический результат

На 36 000 строках (8 поставщиков, 150 моделей) ввод в поле значения отвечает за 18 мс, файл проекта открывается за 0,22 с, смена модели в сравнении — 50 мс.

## Границы текущей версии

- Нет импорта .xlsx: таблица вставляется текстом (из Excel копируется табуляцией).
- Нет допусков поставщика (±1 см) и разных порогов для разных типов замеров.
- Нет сравнения размеров между собой (подбора «M у А = L у Б»): только одинаковая маркировка.
- Данные живут в одном браузере, перенос — файлом.
