# Ассеты и сторонние материалы

Сторонних изображений, шрифтов, звуков и других материалов в проекте нет.

| Файл | Происхождение | Права |
|---|---|---|
| `public/favicon.svg` | нарисован вручную для проекта (линейка и зигзаг, SVG-примитивы) | собственный материал проекта |
| Демо: поставщики «Ткани Севера», «Хлопок-Юг», «Вязальщик», модели «Футболка базовая», «Худи оверсайз» и их замеры | придуманы для проекта, `demoChart()` в `src/core/chart-editor.ts` | синтетические данные, названия вымышлены |
| Проект из 36 000 строк в замере | генерируется тестом `e2e/perf.spec.ts` | синтетические данные |
| Шрифты | системные (`system-ui`), не загружаются | — |

Зависимости npm (React, Vite, TypeScript, Vitest, Playwright и их транзитивные пакеты) не копируются в репозиторий, их точные версии зафиксированы в `package-lock.json`.

## Лицензии кода в сборке

В `dist/` попадает код production-зависимостей: `react`, `react-dom`, `scheduler` (все MIT). Сборщик удаляет лицензионные комментарии, поэтому тексты лицензий лежат отдельно: `public/THIRD_PARTY_LICENSES.txt` → `dist/THIRD_PARTY_LICENSES.txt`. Файл пересобирается из `node_modules` перед каждой сборкой (`scripts/third-party-licenses.mjs`). Dev-зависимости в сборку и ZIP не входят.
